# FAQ

**Do I need a server?** No. The registry is a git repository; `owl` reads `index.json` from a clone.

**Is it safe to install a skill?** Skills are passive text and files; OWL does not execute them. Still,
read what an agent will be told to do, and prefer skills you trust. The content hash detects change but is
not a signature.

**Can I use it with OpenCode, Codex, Gemini CLI, Cursor, Copilot?** Yes – `owl install --target <tool>`.

**How do I propose a skill?** {doc}`guide/contributing`.

**Why are there no author folders?** Flat names keep installs simple; the author is metadata.

**The index looks outdated.** It is regenerated by CI after each merge to `main`.
