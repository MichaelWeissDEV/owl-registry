# Generated index files

Generated by `owl registry index` in CI. Never edit them by hand.

## `index.json` (format 2)

Top level: `format`, `name`, `description`, `generated_at`, `count`, `skills`. Each entry in `skills`:

| Field | Meaning |
| --- | --- |
| `ref`, `author`, `name`, `version`, `description` | identity and summary |
| `tags`, `topics`, `license`, `compatibility` | metadata from frontmatter or `skill.json` |
| `sha256` | content hash over `SKILL.md`, metadata and files |
| `path`, `files`, `size` | location and size |
| `updated_at`, `revision` | last change and git revision, taken from git history |

## `stats.json` (format 2)

`totals` (`skills`, `files`, `size_bytes`, `invalid_entries`) and the breakdowns `by_author`, `by_tag`,
`by_topic`, `by_compatibility` and `by_license`.

`INDEX.md` and `STATS.md` are the same data in readable form.
