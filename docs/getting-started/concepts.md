# Concepts

| Concept | Meaning |
| --- | --- |
| **Skill** | a directory `skills/<name>/` with a `SKILL.md` (YAML frontmatter + instructions) and optional bundled files |
| **Flat layout** | no author directories; the author is metadata (`author:`) |
| **Index** | `index.json` / `INDEX.md` / `stats.json` / `STATS.md`, generated by CI – never edited by hand |
| **Content hash** | SHA-256 over `SKILL.md`, metadata and files; it detects change but is **not** a signature |
| **Passive data** | scripts in a skill are never run by OWL or by CI |

Names are unique in the registry: lower case, digits and single hyphens, at most 64 characters, and the
directory name must equal the `name` in the frontmatter.
